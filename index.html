PJM Canva Promo: Policies

Last updated November 5, 2026

PJM Canva Promo is a personal tool run by Matt Margolis. It creates promotional graphics for Matt's own PJ Media articles and publishes them to his own Facebook Page, Matt Margolis. It is not offered to anyone else, and no one else can sign in to it or connect an account to it.

Privacy Policy

The tool does not collect, store or sell personal information about Facebook users or anyone else. It does not read comments, messages, followers or other people's data.

The tool uses a Facebook Page access token belonging to Matt, stored on his own computer, to publish to his Page. To prepare each post, it uses the public headline, image and link of his article, and it uses Canva to create the graphic and Claude, an AI service from Anthropic, to run the process.

The tool does not use cookies or analytics. This page's hosting provider may keep standard server logs.

Terms of Service

This tool is for Matt Margolis's personal use only and is provided as is, with no warranty. Posts it publishes are subject to Facebook's terms. Nothing here grants anyone else a right to use the tool.

Data Deletion Instructions

The tool stores no personal data about anyone other than Matt, so there is normally nothing to delete. If you believe it holds data about you, or you want something it posted removed, send a message to the Matt Margolis Facebook Page describing your request. Matt will review it and delete any such data or post that applies.
